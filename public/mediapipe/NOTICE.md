# MediaPipe assets

Runtime and WASM files are copied without modification from Google's
`@mediapipe/tasks-vision` npm package, version 1.1.1 (Apache-2.0).

- Package: https://www.npmjs.com/package/@mediapipe/tasks-vision/v/1.1.1
- Project/license: https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE
- Face Landmarker model (float16, version 1):
  https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
- Model documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker

The app-owned tracker.js wrapper is separate from these vendor files.
